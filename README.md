## 📖 About the Project

**University Module Grade Calculator** is a web application built to help university students **calculate their module grade in percentage**.

The student enters the score obtained in each assessment, such as **CAT1**, **CAT2** and **FAT**, together with the weight of that assessment. The calculator then works out how much each assessment contributes and shows the **final grade as a percentage**.

🎯 **The goal:** to let students quickly see where they stand in a module, without doing the calculations by hand.

---

## 🧮 How It Works

1. Type the **assessment name** (for example `CAT1`, `CAT2` or `FAT`).
2. Enter the **score obtained** (0 - 100) and the **weight** of the assessment (1 - 100).
3. Click **ADD ASSESSMENT**.
4. Repeat for each assessment of the module.
5. Read your **Current Final Grade** at the bottom of the page.

### 📌 Example

| Assessment | Score (%) | Weight (%) | Contribution |
|:----------:|:---------:|:----------:|:------------:|
| CAT1 | 80 | 20 | 16 |
| CAT2 | 70 | 20 | 14 |
| FAT | 75 | 60 | 45 |
| **Total** | | **100** | **75%** |

> 💡 The weights above are only an example. Every module can use different weights, so enter the ones given by your lecturer.

## 🚀 Getting Started

To use the calculator locally:

**1.** Clone the repository:

```bash

```

**2.** Open the project folder:

```bash
cd University-Module-Grade-Calculator
```

**3.** Open **`student grade.html`** in your web browser. 🎓

No installation or build tools needed. Just a browser!
